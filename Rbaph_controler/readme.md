# How to use

1. launch Rbaph\_parameters.m
2. If you have mocap launch Controler\_ultime
3. If you dont have mocap, launch Controler\_manette and chose the way you want to controle the robot (adviced mode : R\_L)

# Setup

1. install MATLAB 2023b and Simulink
2. install toolboxs (or add-on) :

   * Optimization Toolbox
   * Robotics System Toolbox
   * Embedded Coder
   * Matlab Coder
   * Simulink Coder
   * Simscape
   * Simscape Multibody
   * Matlab support package for Raspberry Pi hardware
   * Simulink support package for Raspberry Pi hardware
   * (on windows) Matlab support for MinGW-w64 C/C++Compiler

3. install [RPIt](https://www.youtube.com/watch?v=jnNS4pmAGkk) (if it is stuck at passworlessconnection, use ctrl+C and continue with next step)
4. launch "get hardware support package" (if all libraries are not installed, press next and continue)
